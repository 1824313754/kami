# 管理后台操作台说明

本次调整只覆盖 `/admin/files` 与 `/admin/cdkeys` 的顶部工作区与操作台交互。

## 总览

- `/admin` 的“今日总览”展示两组核心指标：今日上传文件、今日提取卡密、今日提取文件数，以及全历史上传文件、全历史提取卡密、全历史提取文件数。
- 总览默认按“当天 + 当前用户范围”统计，不再按当前池子的业务类型和标签拆分，避免首页因为池子切换而误显示为 0。
- 总览补充最近 7 天上传文件数与提取文件数的轻量趋势图，用于直观看每天的波动和对比；当前使用本地静态资源引入的 ECharts 渲染，避免继续维护手写坐标图。

## 设计原则

- 操作台保留单一主入口，不再同时平铺多个同级按钮区。
- 页面顶部控制区压成薄工作带，上传、容量和筛选默认收进抽屉，尽量把首屏空间让给列表。
- 默认优先展示“当前范围动作”，引导先筛选再做整批操作。
- 勾选表格行后，操作台自动切换到“已选动作”，只保留对已选对象直接有价值的按钮。
- 删除、恢复、按文本删除等高风险动作统一收进折叠区，避免与日常操作混排。

## 用户

- 用户页支持删除账号，但只允许删除没有文件、没有卡密、没有上传记录、且没有审计记录的空账号，避免误删后破坏归属链路。

## 文件池

- 顶部进一步简化成“查询条 + 上传抽屉 + 快捷筛选 + 更多筛选”，默认只露出最常用的查询条件。
- 文件操作区改成两条细操作条：命中当前范围时显示范围动作，勾选文件后显示已选动作，不再使用大卡片操作台。
- 默认状态下，只显示范围说明，不开放整池批量动作。
- 存在筛选结果时，主操作区显示“下载当前范围”“测活当前范围”，其余动作收进“更多处理”。
- 勾选文件后，页面切成“测活已选”“恢复测活中”“删除已选”“清空已选”这一条直接操作带。

## 卡密

- 顶部进一步简化成“查询条 + 容量抽屉 + 快捷筛选 + 更多筛选”，默认只露出状态和批次两个高频条件。
- 卡密操作区改成两条细操作条：命中当前范围时显示导出动作，勾选卡密后显示已选删除动作，不再保留大卡片和双标签切换。
- 默认状态下，只显示范围说明，不开放整库删除。
- 存在筛选结果时，主操作区显示“导出当前范围”，范围删除收进“更多处理”。
- “按卡密文本删除”单独收进风险抽屉，不再和主动作混排。
- 超发额度改成顶部常显单行表单，不再通过点击展开；“已预约”统一改为“待占用”，避免误解成已被人工预订。
